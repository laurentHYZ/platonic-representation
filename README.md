# 柏拉图表示定理 · 中文讲解

两个单文件页面，零依赖，直接用浏览器打开。

- **`index.html`** —— 一页讲清：一个画面、三个类比、四组数字、三个常见误解、30 秒版与 3 分钟版、术语表。
  术语的拼音标在汉字上方，可朗读，逐词高亮。
- **`reader.html`** —— 全文朗读器：摘要与各章节，支持 Kokoro（OpenRouter）或浏览器语音，同样逐词高亮。
- **`quiz.html`** —— 术语字卡与测验：60 个核心术语，四种题型（看词选音、看音选词、看义选词、听音选词），
  可听发音，错题追踪，进度存在浏览器本地。
- **`platonic-representation-one-pager.pdf`** —— 一页讲清的打印版（4 页，A4）。

## 课堂：学生名单与抽人

1. 打开首页 `index.html`，展开「课堂：贴一份学生名单」，把名单贴进去（一行一个，也支持逗号、顿号、空格分隔），点「保存名单」。
2. 进入 `quiz.html`，每题上方有老虎机式的**抽人**：点「🎲 抽人」（或按 `P`），名字滚动后停在一位学生上，显示「请 XXX 回答」。
3. 抽人是**公平轮转**：优先抽还没被抽过的人，全班轮完一遍才会重复；换名单会自动重置计数。
4. 勾选「每题自动抽」，每出一道新题就自动滚一次。
5. 本轮结果页会按学生列出「X 对 / Y 错」。

名单和抽人记录都只存在本机浏览器里（`localStorage`），不上传任何服务器。

## 测验怎么用

- **字卡**：先看词，猜读音和意思，点卡片翻面核对；🔊 听发音；「记住了 / 还不熟」会记进熟练度。
- **测验**：每轮 10 题，四种题型混合：看词选拼音、看拼音选词、看释义选词、听发音选词。
- 答错的题会进「只练错题」；熟练度按答对次数累计，顶栏显示 `熟练 n / 60`。
- 键盘：`1–4` 选答案，`回车` 下一题；字卡里 `空格` 翻面、`← →` 换卡。
- 进度只保存在你自己的浏览器（localStorage），换设备或清缓存会重置。

## 朗读

- 默认用浏览器语音（免费、离线）。
- 想用 Kokoro：点页面里的 `⚙`，填自己的 OpenRouter API Key。Key 只保存在你本机的 `localStorage`，**不会**写进本仓库，也不经过任何第三方服务器。
- 遇到网络问题：点 `⚙ → 自检`，会把「连通性 / Key / 合成」三步拆开报错。
